Tired IT Humans LLC

We build the tools we wish we already had.

A small collective of tired IT humans — admins, engineers and tinkerers who got tired of how needlessly painful modern IT has become.

Too much of the job is fighting the tools instead of doing the work: half-documented PowerShell, brittle scripts, portals that bury the one setting you actually need, and yet another console to babysit. We think it should be easier than that — so we build small, focused software that takes the friction out of the day, and we give most of it away.

What we build

azapptoolkit

Windows, macOS, Linux · Open source

A native desktop app for managing and auditing Microsoft Entra ID app registrations, enterprise applications and managed identities. It signs in as you and talks to Microsoft Graph with your own delegated permissions — no PowerShell modules, no scripting, and no service principal of its own holding tokens you cannot audit.

Source Live demo

ninjaone-patch-toolkit

Windows, macOS, Linux · Open source

Patching operations for teams running NinjaOne. Sign in with OAuth 2.0 and PKCE, filter the fleet by organization, location, role and OS, read every pending patch per server, and export the whole compliance picture — aging, reboots, failures — to Excel.

Source Live demo

crt-query

Command line · Windows, macOS, Linux · Open source

Certificate transparency from the command line. It queries the crt.sh public PostgreSQL database directly — no HTTP API, no scraping, no API key — to answer what certificates exist for a name, what is inside one of them, and what is about to expire. Output is a table, JSON, or a CSV file a scheduled job can hand to someone else.

Open source

The desktop tools and crt-query are released under the MIT or Apache-2.0 licences — take them, fork them, ship them. The desktop tools run on your own machine under your own credentials: there is no Tired IT Humans service in the middle, no account to create with us, and nothing of ours to trust with your tenant.

Pull up a chair

Tired IT Humans is open to fellow humans who would rather fix the friction than live with it. If you have an idea for a tool — or a half-built one that needs a second pair of hands — we would like to hear about it.

  • Have an idea? Start a discussion and tell us what is making your IT life painful. That is where most of these start.
  • Want to build? Fork any project, hack on it, and send a pull request. Contributions of every size are welcome.
