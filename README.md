# Tired IT Humans 😮‍💨

We're a small collective of fellow **tired IT humans** — admins, engineers, and tinkerers
who got tired of how needlessly *painful* modern IT has become.

Too much of the job is fighting the tools instead of doing the work: half-documented
PowerShell, brittle scripts, portals that bury the one setting you actually need, and yet
another console to babysit. We think it should be easier than that.

So we build the tools we wish we already had — small, focused, and made to take the friction
out of the day — so we can all spend a little less time fighting IT and a little more time
*enjoying life*.

## What we build

- **[azapptoolkit](https://github.com/tiredithumans/azapptoolkit)** — a native desktop app
  for managing Microsoft Entra ID app registrations. No PowerShell modules, no scripting, no
  service principal of its own — just sign in and go.

*More on the way. Pull up a chair — you look tired too.* ☕
